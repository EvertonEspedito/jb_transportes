# JB Transportes — Fretes e Mudanças

Landing page institucional da JB Transportes, atuando em João Pessoa-PB e no Nordeste desde 2017.

## Stack
React + Vite + Tailwind CSS + lucide-react

## Rodando o projeto
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
```

## Conteúdo editável
Textos, contatos e placeholders (imagens, mapa de rotas, depoimentos) ficam
centralizados em `src/data/content.js`. Substitua os placeholders marcados
como "espaço reservado" por conteúdo real antes da publicação — nenhum
depoimento ou avaliação foi inventado.
